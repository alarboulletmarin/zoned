## Material Symbols — icon set

- **Copyright:** © Google
- **Licence:** Apache License 2.0 — full text in [licenses/APACHE-2.0.txt](licenses/APACHE-2.0.txt)
- **Upstream:** https://github.com/google/material-design-icons
- **Obtained via:** the [`@material-symbols/svg-400`](https://github.com/marella/material-symbols)
  npm package (dev dependency), `sharp/` directory, weight 400
- **Where it lives:** `src/components/icons/index.tsx`

The icons ship as SVG files upstream. **The redistributed form is modified**, as
required by section 4(b) of the licence. The changes are:

- each glyph is wrapped in a React component instead of a standalone `.svg` file
- the `<svg>` wrapper attributes are rewritten: the fixed `width`/`height` become a
  `size` prop, `fill` is bound to `currentColor`, and `aria-hidden` / `focusable`
  are added so icons stay out of the accessibility tree
- the outline and `-fill` variants of a glyph are merged into a single component,
  selected at runtime by the `filled` prop
- **the path data itself is copied verbatim and is not altered**

`src/components/icons/index.tsx` is generated by `scripts/generate-icons.ts` from
`scripts/data/icon-mapping.csv`; the reasoning behind each name is in
[docs/icon-mapping.md](docs/icon-mapping.md).

The upstream package ships **no `NOTICE` file**, so there is no attribution notice
to propagate under section 4(d).

- **Licence:** ISC — full text in [licenses/lucide-ISC.txt](licenses/lucide-ISC.txt)
- **Upstream:** https://github.com/lucide-icons/lucide

Zoned used `lucide-react` as a dependency, then inlined its glyphs by hand into
`src/components/icons/index.tsx` (commit `ce613b0`). Those glyphs have since been
replaced by Material Symbols, but this attribution is **required regardless**, for
two reasons:

1. `GithubIcon`, in `src/components/icons/brand.tsx`, is still drawn from Lucide's
   `github` outline. It is a brand mark with no Material equivalent, so it was kept
   on its original geometry.
2. The git history of this repository redistributes the full inlined Lucide set,
   and the ISC licence attaches to those copies too — publishing the repository
   publishes them.

This notice regularises an attribution that was owed from the moment the glyphs
were inlined and was not present in the repository until now.
